Análise de dados de vendas de supermercados utilizando Python, Pandas e Excel, com cálculos de faturamento, média de vendas e visualização de dados com gráficos.

# Análise de Vendas com Python

Projeto de análise de dados utilizando Python para analisar o faturamento de lojas de supermercado no estado de São Paulo.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Excel

## Análises realizadas

- Soma do faturamento total
- Média de faturamento por mês
- Identificação do maior e menor faturamento
- Cálculo da margem de lucro
-

- Visualização de dados com gráficos
